プライバシーポリシー

2026年11月5日

モノラジオ商会（以下「私たち」）が運営するこのサイト（monoradio.jp）と、番組「ものラジオ」（monoradio102.github.io/myradio）で、情報をどう扱うかをまとめています。

このサイト

このサイトは、Cookie や、アクセス解析のツールを使っていません。サイトを配信しているサービスは、ふつうのウェブサイトと同じく、アクセスの記録（IP アドレス、日時、ブラウザの種類など）を残すことがあります。

番組「ものラジオ」

番組のページも、Cookie や、アクセス解析のツールを使っていません。使いやすくするために、次の情報をお使いのブラウザの中だけに保存します。私たちのところには送られません。

  • 再生速度、音量、表示する言語
  • 途中まで聞いた位置と、聞き終わった回
  • 天気を出す場所

ブラウザの設定から、いつでも消せます。

ページの表示のため、次のところにお使いのブラウザから直接アクセスします。それぞれの運営者が、IP アドレスなどを受け取ります。

  • GitHub Pages：番組のページ、台本、音声の配信
  • Open-Meteo：天気の取得。場所は、ふだんはブラウザのタイムゾーンから決めたおおまかな地点です。「現在地にする」を選んだときだけ、端末の位置情報を使います
  • ニュースのサイト：記事の紹介に、各サイトが公開している画像（OGP 画像）をそのサイトから表示します

応援（GitHub Sponsors）

GitHub Sponsors での支援は、GitHub と Stripe が処理します。カード情報などの支払いの情報を、私たちが受け取ることはありません。GitHub の仕組みにより、支援してくださった方の GitHub のアカウント名、金額、支援者が公開を許した場合はメールアドレスが、私たちに知らされます。これらは、お礼や連絡のためだけに使います。

お問い合わせ

メールで受け取った内容は、お返事のためだけに使い、ほかの人に渡しません。
